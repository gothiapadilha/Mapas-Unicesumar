# Mapas — Desenvolvimento de Jogos Digitais

Repositório com atividades e projetos acadêmicos desenvolvidos durante a formação em **Desenvolvimento de Jogos Digitais na UniCesumar**.

Os materiais registrados aqui fazem parte da trajetória de estudos em programação, desenvolvimento de jogos, game design, lógica, produção visual e outras áreas relacionadas à criação de jogos digitais.

## 📚 Conteúdo do repositório

### 💻 Programação Orientada a Objetos

Atividades práticas utilizando **Java** e conceitos fundamentais de Programação Orientada a Objetos, incluindo:

* Classes e objetos
* Encapsulamento
* Construtores
* Herança
* Polimorfismo
* Interfaces
* Sobrescrita de métodos

### 🧠 Lógica de Programação

Atividades relacionadas à construção de expressões lógicas e utilização de operadores:

* AND
* OR
* NOT
* Expressões condicionais
* Combinação de condições lógicas

### 🎮 Jogos 2D e 3D

Atividades relacionadas ao planejamento e desenvolvimento de jogos, abordando elementos como:

* Conceito de jogo
* Gênero
* Narrativa
* Mecânicas
* Dinâmica
* Estética
* Personagens
* Cenários

### ⭐ Caça Estrelas 3D

Projeto acadêmico de jogo 3D envolvendo elementos de programação e armazenamento de informações.

O projeto trabalha conceitos como:

* Sistema de login
* Coleta de estrelas
* Pontuação
* Registro de partidas
* Armazenamento de dados
* Consultas SQL
* Sistema de ranking

### 🎯 Motores de Jogos

Atividades relacionadas ao estudo e planejamento do uso de motores de jogos, considerando aspectos como:

* Escolha de ferramentas
* Recursos disponíveis
* Colaboração
* Dependências
* Atualizações
* Planejamento de desenvolvimento

### 🎨 Produção e Animação de Jogos

Materiais relacionados à produção visual e animação para jogos, incluindo desenvolvimento de personagens e criação de sequências de animação.

### 🖌️ Design

Atividades envolvendo conceitos de design aplicados ao desenvolvimento de jogos, incluindo identidade visual, criação de elementos gráficos e apresentação de projetos.

### 💡 Mentalidade Criativa e Empreendedora

Atividades relacionadas ao desenvolvimento de ideias e planejamento de projetos, abordando conceitos como:

* Empreendedorismo
* Análise SWOT
* Prototipação
* Validação de ideias
* Criatividade
* Utilização de ferramentas de apoio
