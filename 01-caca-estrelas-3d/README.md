# ⭐ Caça Estrelas 3D

Projeto acadêmico desenvolvido durante a formação em **Desenvolvimento de Jogos Digitais na UniCesumar**.

O projeto consiste em um jogo 3D no qual o jogador deve coletar estrelas e acumular pontos durante a partida.

## 🎮 Sobre o projeto

O **Caça Estrelas 3D** foi desenvolvido como atividade acadêmica, envolvendo conceitos de desenvolvimento de jogos, programação, lógica e armazenamento de informações.

Durante o jogo, o jogador pode realizar o login, coletar estrelas e acompanhar sua pontuação e o tempo de partida.

Ao final da partida, as informações são registradas para posteriormente serem utilizadas no sistema de ranking.

## 🕹️ Principais funcionalidades

* Sistema de login de jogadores
* Coleta de estrelas durante a partida
* Contagem de pontuação
* Registro do tempo de jogo
* Registro das partidas realizadas
* Armazenamento das informações dos jogadores
* Sistema de ranking
* Consulta e ordenação das pontuações

## 🗄️ Banco de dados

O projeto também trabalha com armazenamento de informações relacionadas aos jogadores e às partidas.

Entre os dados utilizados estão:

* Jogadores
* Partidas
* Pontuação
* Tempo de jogo

Ao finalizar uma partida, os dados são enviados para o banco de dados.

Também foi utilizada uma consulta SQL para ordenar as pontuações e obter os jogadores com melhores resultados, permitindo a criação de um **ranking com os cinco melhores jogadores**.

## 🧠 Conceitos trabalhados

Durante o desenvolvimento do projeto foram trabalhados conceitos relacionados a:

* Lógica de programação
* Programação
* Desenvolvimento de jogos 3D
* Banco de dados
* SQL
* Organização e armazenamento de informações
* Sistemas de pontuação e ranking

## 📚 Contexto acadêmico

Este projeto faz parte das atividades desenvolvidas durante o curso de **Desenvolvimento de Jogos Digitais da UniCesumar**.

O objetivo da atividade foi aplicar conhecimentos estudados durante a formação em um projeto envolvendo desenvolvimento de um jogo e gerenciamento de dados.
